# Course & Skill Validation — Findings + Fix Plan

## Validation findings (what the deep dive found)

**Inventory**: 5 courses / 65 lessons (all free), 5 text-only bytes, 43 skill definitions vs 55 declared SkillIds, 4 drill generators. Every lesson has a bespoke visual (31 interactive widgets, 32 animated scenes, **2 static**: `DriftSlowlyGoingBad`, `DashboardsControlRoom`). 222 MCQs total; only **4/65 lessons** have runnable Python.

**Validated defects**
1. **Skills layer is dead + broken**: 12 SkillIds used by lessons have no definition in `content/skills.ts` (`k-nearest-neighbors`, `overfitting`, `train-test-split`, etc.); `skills.ts` is imported by zero files; `skillEvidence` is write-only.
2. **42 observability lessons missing from the daily plan**: `TRACK_UNITS` in `convex/lib/dailyPlan.ts` covers only ML lessons + bytes — "next unit" on `/today` never surfaces the AI/LLM Observability courses.
3. **Layman course is bimodal**: 9 of 19 lessons (1–3, the paradigm deep-dives, 18–19) have no prose, often no prediction/application — a fraction of the density of the other 42 lessons.
4. **ML course overlap**: the 4-lesson "Machine Learning" (intermediate) repeats Layman content (AI/ML/DL, paradigms, kNN, trees).
5. **CoursePager title bug**: derives title from slug → "Llm Observability" (wrong casing).
6. **Fake testimonials** hardcoded on the home page (reputational risk).
7. UX: no next-lesson CTA at the reward moment, no in-lesson progress, no per-lesson minutes/prerequisites on course page, no syntax highlighting anywhere, no MCQ keyboard support.
8. Retention: reward vocabulary is one CSS banner — no level-up modal, streak-milestone, or course-completion moment; leaderboard component orphaned; admin replies never shown to users; engagement doc's "no emails" claim is stale (Resend crons exist).

## Phase 0 — P0 validation fixes
1. **`content/skills.ts`**: add the 12 missing definitions (capability-statement style matching existing entries). Add colocated test: every `SkillId` in `content/types.ts` has a `SKILLS` entry, no orphans, descriptions non-trivial.
2. **Wire skills into UI**: course page shows skill labels under the skill map; lesson meta chips show trained skills; `/progress` groups "Capabilities earned" by skill cluster.
3. **`convex/lib/dailyPlan.ts`**: extend `TRACK_UNITS` per track — beginner: + AI Observability (14); grad: + AI Obs → LLM Obs; engineer: + LLM Obs → Reliability; founder: + AI Obs. Add test: every course lesson slug appears in at least one track.
4. **`components/CoursePager.tsx`**: pass the real course title in as a prop (kill `courseTitle()` slug-casing hack).
5. **Animate the 2 static infographics** (`DriftSlowlyGoingBad.tsx`, `DashboardsControlRoom.tsx`) with Reveal/Stagger per the v4 skill; add a small interaction to at least one.
6. **`app/page.tsx`**: remove fictional testimonials; replace with an honest section (learning principles / real stats).
7. **Docs**: refresh the stale email claims in `docs/engagement-and-retention.md`.

## Phase 1 — Learnability UX
1. **Next-lesson CTA at the reward moment**: thread next-lesson href into `RewardBanner` (via `ByteBody`); primary CTA "Next lesson →"; last lesson → course-complete moment (Phase 2).
2. **In-lesson reading progress bar**: thin scroll-linked bar under the Shell header (client, `prefers-reduced-motion` safe).
3. **Course page**: per-lesson minutes on curriculum cards, total-time chip, prerequisites line (add optional `prerequisites?: string[]` to Course).
4. **MCQ keyboard shortcuts**: shared `useChoiceKeys` hook (1–4 select, Enter confirm) in `PredictionCard`, `ByteBody`, `DrillPlayer`, `AuthoredReviewPlayer`.
5. **Syntax highlighting**: add `shiki` (SSR, dual light/dark theme) to `BlockList` code blocks, byte pages, `CodePanel`. CodeCell textarea stays plain (future work).

## Phase 2 — Celebration & retention
1. **`<CelebrationModal>`** (motion lib, reduced-motion safe): level-up variant with capability statement; streak-milestone variant (7/30/100 + freeze earned). Triggered from `RewardBanner` state.
2. **Course-completion moment**: on completing the last lesson — celebratory end state summarizing skills earned + **next-course recommendation** (new `NEXT_COURSE` map in `content/courses.ts`: Layman → ML primer → AI Obs → LLM Obs → Reliability) + copy-link share. Also replaces CoursePager's flat completion card.
3. **Milestones on `/progress`**: derived from existing data (`byteProgress`, streak, XP totals, analytics counts) via a `getMilestones` Convex query — first lesson, first course, 7-day streak, level 5, 100 correct, first code-test pass. No new tables. Rendered as locked/unlocked grid.
4. **Yesterday's misconceptions on `/today`**: query recent wrong-attempt topics; add a "Repair" card linking to the related lesson/byte (the data already exists).
5. **Leaderboard**: delete the orphaned global-XP `Leaderboard.tsx` + query per the documented strategy decision.
6. **Feedback replies**: surface `adminReply` to the user (Profile or a small inbox on `/settings`).

## Phase 3 — Content depth (authored with `infographics-interactive_v4`, beginner calibration)
1. **Thicken the 9 thin Layman lessons**: add prediction MCQ, 2–3 prose paragraphs, application prompt, +1 MCQ each. Enforce with a content test: every lesson needs prose ≥ 2 paragraphs, questions ≥ 2, prediction, application.
2. **Reposition ML course as quick primer**: description "the 18-minute primer", level → beginner-friendly framing, dedupe overlapping copy with cross-links ("go deeper: ML for Layman, Lesson N"). Slugs stay stable.
3. **Add runnable exercises**: 2–3 in Layman (e.g., implement the kNN majority vote in `CodeCell` — the machinery already exists) and 1 in AI Observability.
