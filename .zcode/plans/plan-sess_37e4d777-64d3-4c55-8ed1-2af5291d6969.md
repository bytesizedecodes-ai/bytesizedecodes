# Redesign the Observability + RAG trilogies to the v1 level skills

Bring all 6 courses from the old generic v6 contract to the persona-calibrated v1 level skills, replicating the ML trilogy redesign (`d0f6188` + `f000768`). 66 lessons total, all primarily in `content/courses.ts`.

**Courses:** `ai-observability` (beginner, 14 lessons) · `rag-engineering-foundations` (beginner, 7) · `llm-observability` (intermediate, 13) · `rag-engineering-in-practice` (intermediate, 9) · `ai-observability-reliability` (expert, 15) · `rag-engineering-at-scale` (expert, 8)

## Per-level changes

**Beginner** (per `infographics-interactive-beginner_v1`):
- Recalibrate `concept.anchor` to one playful, touchable everyday object that the existing infographic component actually dramatizes; keep component-compatible anchors (car dashboard, sandwich slicing), rewrite abstract ones. Anchor is the through-line.
- Restructure prose to Hook → anchor → tension → reveal + fade → resolution, with an explicit "where the analogy breaks" line.
- Every `content/jargon-terms.ts` term glossed parenthetically at first use (jargon gate is automated for beginner courses — must stay green).
- No formulas/code — counting, percentages, pictures only.
- MCQs: exactly 2 scenario MCQs, **3 choices**; distractors rewritten as named beginner misconceptions (no filler); Q2 transfers to a new situation.
- Add `flow`/`compare` diagrams where the component isn't already the system view (ai-observability has only 4/14 — target ~8–10/14); skip when duplicative.

**Intermediate** (per `infographics-interactive-intermediate_v1`):
- Compress anchors to a one-line lead-in, then fade to the formal mechanism.
- Rewrite prose to Predict–Investigate–Case: case scenario → predict invitation → evidence in the picture → **First-Principles Ladder** derivation (3–5 "because" rungs from an accepted ground truth, concept named only at the top rung).
- Mandatory case continuity: every lesson adds one named piece of evidence/constraint/decision to the existing running case (llm-observability: support-assistant incident; rag-in-practice: Atlas).
- MCQs: 3–4 choices, practitioner-misconception distractors (retrain-first reflex, bigger-model reflex); **Q2 re-derives one ladder rung in a new situation**.
- Moderate inline Unicode formulas (error budget `1 − SLO`, burn rate; cosine similarity, recall@k/NDCG) and runnable Pyodide exercises where genuine (~4–6 per course; llm-observability keeps/upgrades its 3).

**Expert** (per `infographics-interactive-expert_v1`):
- Anchors become one terse professional line.
- Rewrite prose problem-first (no warm-up): failing system → you-diagnose → ladder from **fundamental constraints** (3–4 rungs; grounds = physical limits, math, cost structure — never best practices) → **mandatory Boundary beat** (which constraint, when relaxed, flips the conclusion) → What/So-What/Now-What.
- Sharpen the competing-constraint production cases (reliability: multi-agent financial-research system; rag-at-scale: Atlas at 40k docs); each lesson adds evidence, uncertainty, or a counter-example; capstone = design review over the accumulated case.
- Full formulas + real failure modes inline; add exercises where they fit (~2–4 per course).
- MCQs: 3–4 choices, production scenarios; Q2 = which constraint, when relaxed, flips the conclusion.
- Fill diagram gaps in `ai-observability-reliability` (8/15) — decision trees for boundary conditions.

## Method

- Locate course blocks by **slug, not line numbers** (file is shifting under concurrent edits).
- Before each course: load the matching SKILL.md + its `references/lesson-contract.md` (and `first-principles-ladder.md` for intermediate/expert); draft per-lesson contracts (objective verb, aha, likely wrong conclusion, case add) before rewriting.
- Infographic components: light pass only — fix scenes that contradict a changed anchor or grossly violate level density (~3 elements beginner); no full component rebuilds.
- No new lessons planned → no changes to `components/infographic/index.tsx` / `convex/lib/dailyPlan.ts` unless a lesson clearly contains two ladders and must split (if so, register fully: component + index + `unit()`).
- **Concurrent fine-tuning work (user-approved): proceed in parallel.** Edit only the Observability/RAG blocks; registration files additively only; never touch the fine-tuning course region (~line 11259+) or its new components; re-check `git status` before each edit batch.
