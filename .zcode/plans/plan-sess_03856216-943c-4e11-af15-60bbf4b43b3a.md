# infographics-interactive_v6 — integrating the four findings

Create **v6** as the new default skill (repo convention: fork v5, mark it superseded-retained), and ship the supporting code contract, tests, share artifact, and full 138-lesson backfill.

## A. New skill — `.agents/skills/infographics-interactive_v6/`

Fork of v5 (SKILL.md + 8 references + 4 assets copied), then apply deltas:

1. **§0 — Anchor-first Concept Brief.** Brief gains a mandatory 5th field rendered FIRST: `anchor` — one sentence mapping the concept to something a 10-year-old touches ("Gradient descent is like hiking down a foggy mountain"), before any nodes, vectors, or code. Level-calibrated flavor: beginner = playful everyday object that doubles as the story infographic's through-line object (ties into §1.3); intermediate = quick lead-in then fade; expert = one terse professional line ("a circuit breaker for predictions"). Present at ALL levels.
2. **§6 upgrade — Continuous Interactive Playgrounds.** The three gates stay, but when interaction is earned AND the concept has a tunable knob or toggleable state, the control must be *continuous* (drag/flip → immediate visible consequence on the picture), not only discrete step-reveals. Named examples: learning-rate slider on gradient descent; RAG ON/OFF toggle flipping hallucination → cited documents. New shared primitives live in `components/infographic/controls.tsx`.
3. **New plain-English gate (jargon elimination).** No technical buzzword without an immediate parenthetical translation on first use in brief/prose (hyperparameters → "tuning dials", loss → "error score", weights → "importance sliders", embedding → "meaning coordinates", drift → "going stale", …). Level-calibrated: beginner = every listed term; intermediate = uncommon terms; expert = exempt. Enforced by an automated test (see C).
4. **New §4.7 — The shareable cheat-sheet layer.** Every lesson auto-derives a cheat-sheet card (anchor + What + When NOT + BSD mark + lesson URL) — no new authoring fields. Rendered in-lesson after the MCQs with Download-PNG / Share-on-X / Share-on-LinkedIn / Copy-link; the lesson OG image becomes this card so social link previews do the marketing.
5. **Workflow (Steps 0–5) updated:** contract adds anchor + playground decisions; Step 5 verification adds anchor check, continuity-of-playground check, jargon check (`npm test`), cheat-sheet check (renders both themes, PNG route works, OG matches).
6. **What NOT to do additions:** no jargon before the anchor; no discrete presets where a knob begs to be dragged; no unglossed listed terms in beginner/intermediate courses; no hand-rolled sliders/toggles — use `controls.tsx`.
7. Update `references/interactivity-patterns.md` (continuous-playground pattern) and `references/lesson-contract.md` (anchor + playground fields).
8. **Mark v5 superseded:** edit `infographics-interactive_v5/SKILL.md` frontmatter/header → "SUPERSEDED by v6 — retained legacy" (mirrors how v4 was marked).
