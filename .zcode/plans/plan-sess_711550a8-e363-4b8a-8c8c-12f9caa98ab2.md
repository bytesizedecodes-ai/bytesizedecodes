## Change 4 — Unify pill/tag styles: extend `Tag` primitive
L1 uses `Tag` (ash border); L4 invented a brand-wash pill with a dot. One pill style for the same job.

**Extend `Tag` in `primitives.tsx`** with an optional `tone`:
```tsx
export function Tag({ children, tone = "neutral", dot = false }: {
  children: ReactNode;
  tone?: "neutral" | "brand";
  dot?: boolean;
}) {
  const cls = tone === "brand"
    ? "border-brand bg-brand-wash text-brand"
    : "border-ash bg-surface-elevated text-ink";
  return (
    <span className={`inline-flex items-center gap-1.5 rounded-full border px-2.5 py-0.5 text-[10px] font-bold uppercase tracking-wide ${cls}`}>
      {dot && <span aria-hidden="true" className="h-1.5 w-1.5 rounded-full bg-current" />}
      {children}
    </span>
  );
}
```

**`AIVsMLVsDL.tsx`:** replace the custom `DotCase` label span with `<Tag tone="brand" dot>{place}</Tag>`. Keep the rest of `DotCase`.
