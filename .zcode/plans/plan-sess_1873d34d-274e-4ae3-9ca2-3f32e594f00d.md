## Plan: Retrofit 9 passive AI Observability lessons into interactive v3 widgets

### Context (what I confirmed)
- The AI Observability beginner course is **already built and wired** in the working tree (uncommitted on branch `001-khan`): 14 lessons in `content/courses.ts:1100`, each slug-mapped to a component in `components/infographic/index.tsx`.
- Of the 14, **only 3 are interactive** (`MetricsDashboard`, `TraceWaterfall`, `AlertThresholdTuner`). The other **9 are passive** (v2-style `Scene`/`Stagger` scroll-reveals).
- The `infographics-interactive` (v3) skill's headline rule is **P8 — "Active beats passive."** You selected Quality + Action + Foundations/pillars — i.e. retrofit those 9. The 2 capstones (`observability-toolkit`, `day-in-the-life`) stay passive on purpose (narrative lessons).

### Key simplification
**Only the 9 component files change.** Each keeps the same file path and same named export, so:
- No edits to `components/infographic/index.tsx` (slug→component map is unchanged)
- No edits to `content/courses.ts`, `content/skills.ts`, `content/types.ts`
- The Constructive "predict" beat lives **inside** each component (in `<InfographicHeader subtitle>` / an in-widget prompt), not in the course `prose`/`prediction` data

### Hard design constraints (every lesson)
1. **Beginner calibration** — constrain to 2–3 presets (no open sandbox); preserve the Anchored Story-Mountain arc: Hook in the header subtitle, predict-prompt = tension, interaction = reveal+fade, `<Takeaway>` = resolution.
2. **Real accessible controls** — `<button aria-pressed>` group for toggles, `<button role="listitem">` for elaborate rows, `<input type="range" aria-label>` for tuners. No `<div>` controls.
3. **One Constructive beat each** — a predict-then-reveal prompt before the interaction (P8 + retrieval-practice).
4. **Theme-safe tokens only** — `bg-surface-elevated`, `bg-canvas`, `border-ash`, `text-ink`, `text-ink-soft`, `bg-brand`/`bg-brand-wash`, `text-brand`, `accent-brand`. `var(--color-bad)` reserved for the **single semantic anomaly** per scene. Never `bg-white`/`text-white`/literal hex.
5. **Reduced-motion-safe by construction** — wrap in `<Infographic>` (provides `MotionConfig reducedMotion="user"`); state carries meaning, not motion.
6. **Package is `motion`** (`motion/react`), never `framer-motion`.
