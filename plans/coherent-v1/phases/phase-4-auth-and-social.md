# Phase 4 — Authentication and real social learning

/** Status: technical foundation started (auth + projects schema, 2026-07-31). */

## Authentication

- Add Convex Auth with Google OAuth.
- Resolve identity on the server.
- Remove client-trusted user IDs.
- Migrate anonymous progress after signup.
- Add privacy and deletion/export controls.

## Social work

Start with:

1. Opt-in project gallery
2. Compare explanations after answering
3. Rubric-based project review
4. Small goal-based study squads

Do not ship:

- Global lifetime XP leaderboard
- Public progress by default
- Free-form direct messages
- Unmoderated forum

## Exit criteria

- Anonymous progress migrates without duplication.
- Users control project visibility.
- Peer feedback is useful under a simple rating/rubric.
- Abuse reporting and moderation paths exist before open submission.
