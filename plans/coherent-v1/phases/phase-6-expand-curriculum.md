# Phase 6 — Expand the curriculum based on evidence

Parent: [`../05-product-execution-roadmap.md`](../05-product-execution-roadmap.md)

Only after the previous loop works:

- Classical ML course
- Deep learning course
- LLM application engineering course
- AI systems/MLOps course
- Role-specific overlays
- Interview practice overlay

Prioritize based on:

- Learner goal demand
- Prerequisite gaps observed in attempts
- Project abandonment points
- Delayed-test performance
- Reusable generator potential

Do not prioritize based only on social-media topic popularity.
