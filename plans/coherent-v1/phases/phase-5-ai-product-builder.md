# Phase 5 — AI Product Builder

Parent: [`../05-product-execution-roadmap.md`](../05-product-execution-roadmap.md)  
Duration: 8–12 weeks, released in stages

## Starter project

Use one shared project with audience-specific depth:

> Build and evaluate a grounded FAQ assistant.

### Beginner route

- Define good and bad answers
- Test a provided prototype
- Identify hallucinations
- Create a responsible-use guide

### Student route

- Implement retrieval
- Build an evaluation set
- Measure quality and latency
- Deploy a demo

### Professional route

- Map the workflow
- Design human escalation
- Define adoption and quality metrics
- Produce an integration proposal

### Founder route

- Interview target users
- Validate urgency
- Build the smallest evaluator
- Estimate cost
- Test willingness to pay
- Launch a narrow MVP

## Founder artifact system

Persist:

- Problem brief
- Interview notes
- Evaluation cases
- Architecture
- Cost model
- Demo URL
- Risk register
- Launch experiment
- Continue/pivot/stop decision

## Exit criteria

- Ten testers begin with a real problem.
- At least five complete customer/problem evidence.
- At least three deploy a working evaluated prototype.
- At least one gains repeated external use; revenue is useful but not required
  for curriculum validation.
