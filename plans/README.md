# Plans

Product and delivery planning lives here. **Do not treat these as the current
codebase source of truth** — for that, read `docs/` and `CLAUDE.md`.

Whenever you create or update product plans, roadmaps, audits, or phased
delivery docs, put them under this `plans/` folder (not `docs/`).

| Planning phase | Path | What it is |
| --- | --- | --- |
| Historical (frontend-first prototype) | [`historical/`](./historical/) | Early product, architecture, generators, Phase-0 localStorage plan |
| Coherent V1 (current direction) | [`coherent-v1/`](./coherent-v1/) | Audit, engagement, curriculum, interaction design, phased execution |

Execution work inside Coherent V1 is split by delivery phase under
[`coherent-v1/phases/`](./coherent-v1/phases/).
