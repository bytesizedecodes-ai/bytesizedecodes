Encryption vs Hashing

Two security concepts that always get confused

Encryption

Reversible — you can get the original back

PurposeKeep data secret
Reversible?Yes — with a key
ExampleHTTPS, WhatsApp messages

Hashing

One-way — you can't reverse it

PurposeVerify data integrity
Reversible?No — it's a fingerprint
ExamplePasswords, file checksums
