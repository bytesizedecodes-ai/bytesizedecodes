AI Agents in Practice · Lesson 01

How an AI Agent Thinks: Thought → Action → Observation

The ReAct loop — every agent you'll ever debug runs on these three words
💳

The story: A customer asks a support agent — "Why did my payment pay_9x2f decline?" The agent can't know. But it knows how to find out. Watch it think:

STEP 1 · THE MODEL

💭 Thought

the agent reasons

"I can't explain a decline without the payment record. Fetch it first."

Plan before you act — the thought steers the next move.
STEP 2 · THE MODEL

⚡ Action

the agent asks — it cannot run

The reply is a tool call: a structured request your code must execute.

get_payment("pay_9x2f")
STEP 3 · YOUR CODE

👁 Observation

the harness answers

Your code runs the tool and appends the result to the transcript.

{ status: declined, reason: insufficient_funds }
↻ loop again — thought, act, observe — until the model can answer

💬 Final Answer

  • "pay_9x2f declined — insufficient funds (₹2,450)."
  • 3 turns · 2 tool calls · every turn re-read the full transcript
  • The transcript is the agent's only memory
